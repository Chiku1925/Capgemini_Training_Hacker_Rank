# Capgemini Training - HackerRank Solutions (Day 4)

This directory contains Java solutions for Day 4 of the Capgemini Training HackerRank exercises. The focus is on string manipulation, anagrams, palindromes, regex, and related input/output handling.

## 🗂️ Files and Topics Covered

### ✅ `Question15.java` – Lexicographical Substrings
- **Topic**: String Manipulation  
- **Description**:  
  Finds the lexicographically smallest and largest substrings of a given length `k` from a string.

---

### ✅ `Question16.java` – Palindrome Check
- **Topic**: String Reversal, Conditionals  
- **Description**:  
  Checks if a given string is a palindrome by comparing it with its reverse.

---

### ✅ `Question17.java` – Anagram Check
- **Topic**: String Manipulation, Sorting  
- **Description**:  
  Determines if two strings are anagrams by sorting their characters and comparing equality, ignoring case.

---

### ✅ `Question18.java` – String Tokenization
- **Topic**: String Splitting, Regex  
- **Description**:  
  Splits a sentence into tokens based on multiple delimiters (spaces, punctuation) and prints the number of tokens and each token.

---

### ✅ `Question19.java` – Regex Pattern Validation
- **Topic**: Regular Expressions, Exception Handling  
- **Description**:  
  Validates multiple regex patterns input by the user and prints "Valid" if the pattern compiles, otherwise "Invalid".

---

## 📝 Notes

- These exercises reinforce working with strings, including advanced manipulations and regular expressions.
- They demonstrate exception handling in the context of regex compilation.
- The problems cover practical tasks like palindrome checking, anagram validation, and input tokenization.
