# Capgemini Training - HackerRank Solutions (Day 5)

This directory contains Java solutions for Day 5 of the Capgemini Training HackerRank exercises. The focus is on regex validation, `BigInteger` operations, arrays, and 2D array manipulations.

---

## 🗂️ Files and Topics Covered

### ✅ `Question20.java` – Username Validator
- **Topic**: Regular Expressions  
- **Description**:  
  Validates usernames using a regex pattern. A valid username must start with a letter and be between 8 and 30 characters, using only alphanumeric characters and underscores.

---

### ✅ `Question21.java` – Prime Check Using BigInteger
- **Topic**: BigInteger, Primality Test  
- **Description**:  
  Uses `BigInteger.isProbablePrime()` to check whether the given large number is a prime or not.

---

### ✅ `Question22.java` – BigInteger Addition and Multiplication
- **Topic**: BigInteger Operations  
- **Description**:  
  Reads two large numbers using `BigInteger`, prints their sum and product.

---

### ✅ `Question23.java` – Array Element Printer
- **Topic**: Arrays, Looping  
- **Description**:  
  Reads an array of integers and prints each element on a new line using standard loops.

---

### ✅ `Question24.java` – 2D Array Hourglass Sum
- **Topic**: 2D Arrays, Nested Loops  
- **Description**:  
  Calculates and prints the maximum hourglass sum in a 6x6 2D array.

---

## 📝 Notes

- These exercises reinforce concepts such as regex validation, high-precision arithmetic, and multi-dimensional array processing.
- They focus on solving real-world problems like form input validation and data structure traversal.
- Practice with `BigInteger` and `BufferedReader` is useful for handling large numbers and efficient input.
