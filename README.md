# Capgemini Training - HackerRank Solutions (Day 1)

This directory contains Java solutions for Day 1 of the Capgemini Training HackerRank exercises. The focus is on basic Java input/output and simple programming constructs.

## 🗂️ Files and Topics Covered

### ✅ `Question1.java` – Hello World
- **Topic**: Basic Output  
- **Description**:  
  Prints two lines: "Hello, World." and "Hello, Java."  
  This exercise introduces basic Java syntax and output.

---

### ✅ `Question2.java` – Reading Integers from Input
- **Topic**: Input Handling  
- **Description**:  
  Reads three integers from the standard input and prints each on a new line.  
  This exercise practices reading multiple inputs using `Scanner`.

---

### ✅ `Question3.java` – Input of Different Types and Output Formatting
- **Topic**: Input Handling, Data Types  
- **Description**:  
  Reads an integer, a double, and a string from input, then prints them in a formatted manner.  
  Demonstrates reading mixed data types and formatting output.

---

## 📝 Notes

- These exercises serve as an introduction to Java syntax, input/output operations, and data types.
- They build foundational skills for further Java programming challenges.
