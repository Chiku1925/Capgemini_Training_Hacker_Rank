# Capgemini Training - HackerRank Solutions (Day 3)

This directory contains Java solutions for Day 3 of the Capgemini Training HackerRank exercises. The problems cover string manipulation, comparison, substring extraction, and localization concepts in Java.

## 🗂️ Files and Topics Covered

### ✅ `Question12.java` – Currency Formatter
- **Topic**: Number Formatting, Localization  
- **Description**:  
  Reads a payment amount as a double and prints it formatted as currency for different locales: US, India, China, and France.  
  Utilizes `NumberFormat.getCurrencyInstance(Locale)` to apply locale-specific currency formats.

---

### ✅ `Question13.java` – String Operations and Comparison
- **Topic**: String Manipulation, Lexicographic Comparison  
- **Description**:  
  Takes two strings as input, prints the sum of their lengths, checks lexicographic order to print “Yes” or “No”,  
  then capitalizes the first letter of each string before printing them.

---

### ✅ `Question14.java` – Substring Extraction
- **Topic**: String Manipulation  
- **Description**:  
  Reads a string and two integer indices, then prints the substring of the string from the start index (inclusive) to the end index (exclusive).

---

## 📝 Notes

- These exercises help reinforce fundamental Java string handling methods and locale-aware formatting.
- The problems are part of the Capgemini HackerRank Java training exercises.
