# Capgemini Training - HackerRank Solutions (Day 1)

This directory contains Java solutions for Day 1 of the Capgemini Training HackerRank exercises. These problems focus on foundational Java concepts like input/output, string manipulation, loops, and conditional logic.

## 🗂️ Files and Topics Covered

### ✅ `Question1.java` – String Tokenization
- **Topic**: String Handling, Regular Expressions
- **Description**: 
  Splits a sentence into words based on special character delimiters like spaces, punctuation, etc., using regex. Also handles empty or whitespace-only input by checking after trimming.

---

### ✅ `Question2.java` – Java Output Formatting
- **Topic**: Input/Output Formatting
- **Description**: 
  Reads a set of string-integer pairs and prints them in a formatted manner using `printf`, ensuring consistent alignment.

---

### ✅ `Question3.java` – Static Initialization Block
- **Topic**: Static Blocks, Exception Handling
- **Description**: 
  Uses a static initialization block to validate input for breadth and height of a parallelogram. If the input is invalid (negative or zero), throws an exception before any other code runs.

---
